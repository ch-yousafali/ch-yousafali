# About Me

<div align="center">

### Computational Physics Student • ML for Physics • 3D Artist • Full Stack Builder

I study physics and build software at the same time. Right now I work on two tracks: using machine learning to classify particle physics data, and building products — from a 3D asset marketplace to game art for studios.

# What I'm Working On Right Now

**Research (Thesis Project)**
Working on a thesis using Machine Learning to classify particle jets, using open data from CERN. Comparing CNN and GNN models on the Top Quark Tagging Reference Dataset. Currently training the full model on Google Colab GPU to push accuracy higher.

**Polymart**
Building a 3D asset marketplace website for game developers — similar to Sketchfab or CGTrader — using Next.js, Cloudflare, and Stripe.

**Rendering**
Running my own studio called Rendering, which creates Blender-based 3D assets, environments, and visual content for game developers and animation studios.
